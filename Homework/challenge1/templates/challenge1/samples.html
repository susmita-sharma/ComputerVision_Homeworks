Context-aware hierarchical robot control: does an environment-understanding phase with a Video-LLM improve robot operation in an unseen home, without retraining any model?

Method

Perception (Video-LLM on a walkthrough video) → Reasoning (VLM with the task) → Environment grounding (structured JSON context) → Low-level policy (actions)

ComponentUsed here
Video-LLM and VLMQwen2.5-VL-3B-Instruct, frozen
High-level reasoningSame VLM, prompted with the task and scene summary
Low-level policyScripted pick-and-place controller, standing in for a learned policy
EvaluatorOWLv2 detector, giving a pseudo ground-truth box for the target

Baseline: no scene context, uses a preset grasp location and counter height. Context-aware: watches the scene first, then grounds the task. Each home is tested in normal light and in dim light (simulated at 35% brightness).

Findings

  • Feasibility: a frozen Video-LLM can turn a short walkthrough of an unseen home into structured context and ground the task target in pixels, with prompting and no retraining.
  • Baseline vs. context-aware: the preset baseline fits a new home only if it happens to match the training layout. The context-aware layer adapts the grasp point and surface height per home.
  • Lighting: the dim condition shows how robust the grounding is to changing light. Any IoU drop shows where better perception is needed.
  • Limitations: 2-D pixel targets only, OWLv2 boxes are pseudo ground truth, the policy is scripted, and the number of homes is small.
  • Next steps: add depth for 3-D grounding, feed the context into a learned policy in a simulator, and test more homes and clutter levels.
